# Bessel Systems – Centralized QR Code Guest Wi-Fi

This system issues temporary, QR-based guest internet access at the Bangalore (FortiGate 60F) and Hyderabad (FortiGate 30G) offices.

- **Reception** registers and approves visitors, then prints a pass with a QR code.
- **The guest** scans the QR code on the guest SSID.
- **The FortiGate** enforces access through its captive portal and RADIUS, and ends it automatically when the approved time runs out.

```
docker-compose.yml        nginx · frontend · backend · worker · FreeRADIUS · PostgreSQL
.env.example              configuration template (secrets generated by scripts/gen-secrets.sh)
backend/                  FastAPI app, guest portal, RADIUS decision API, worker, Alembic migrations, lab tests
frontend/                 React admin / reception console
deploy/freeradius/        FreeRADIUS 3.2 + rlm_rest config
deploy/nginx/             reverse proxy (admin vhost + guest vhost), admin allow-list
scripts/                  install, gen-secrets, backup, restore, upgrade, discovery, lab certificate
docs/                     design, device configuration plans, manuals, tests
```

## Current status

- **Application layer:** built and lab-verified end to end. The lab used real FreeRADIUS, PostgreSQL and nginx with simulated FortiGate RADIUS/CoA peers (70/70 checks).
- **Network layer:** designed. Exact FortiGate and Omada commands are finalised only after the discovery data (`docs/00-discovery-checklist.md`) is reviewed. No interface names, VLAN IDs, IPs or firmware capabilities have been assumed.

## Quick start (lab)

```bash
cp .env.example .env && ./scripts/gen-secrets.sh
cp deploy/nginx/admin-allow.conf.example deploy/nginx/admin-allow.conf   # add your admin subnets
./scripts/selfsigned-cert.sh        # lab only
./scripts/install.sh
docker compose exec backend python -m app.cli create-superadmin admin "Your Name"
```

For production, follow `docs/06-deployment-manual.md`.
